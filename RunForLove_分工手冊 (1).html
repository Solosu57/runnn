六大工作組別分工

賽前準備 · 當天執行 · 賽後收尾

廠商組 組長：nikki　協助：Jax、石頭

賽前準備

  • 確認廠商出席名單（到場 vs 寄商品）
  • 確認廠商提供商品與數量
  • 規劃桌椅數量、動線與位置
  • 製作廠商桌牌
  • 確認 NID 給廠商的曝光內容

當天執行

  • 協助廠商 13:00 進場就位
  • 確認展示桌位整齊、桌牌放好
  • 抽獎商品清點並交比賽組保管

賽後收尾

  • 協助廠商撤場
  • 發出廠商曝光貼文（限動/IG）
報到 / 捐衣組 組長：宸瑨　協助：阿哲、明儒

賽前準備

  • 設計雙軌報到動線，避免人潮卡關
  • 準備報到桌與告示標示
  • 統一裝袋活動物資
  • 制定捐衣驗收標準（九成新，太舊請帶回）

當天執行

  • 15:00 開放報到，發放活動物資
  • 引導至捐衣區，驗收品質
  • 衣服分類 S～2XL，即時統計件數
  • 不合格品請參與者帶回

賽後收尾

  • 18:40 公布捐衣總件數
  • 交接給捐好好捐協會
比賽組 大人裁判長：JAX　小孩裁判長：潘廣

賽前準備

  • 確認分組名單與賽制流程
  • 備妥計時設備、哨子、獎品
  • 確認裁判（宸瑨/阿哲/明儒/OA/子弘）
  • 安排NBA體測4人、出入管制3人

當天執行

  • 石頭負責倒數響哨（16:00 準時）
  • 大人組：趣味賽 / 400M / 大隊接力
  • 小孩組：趣味賽 / 大隊接力 / NBA體測
  • 18:00 執行頒獎與抽獎

賽後收尾

  • 整理成績紀錄
  • 回收裁判計時設備

六大工作組別分工（續）+ 關鍵風險提醒

器材組 組長：nikki　協助：潘廣 + 暴龍隊（共8人）

賽前準備

  • 確認所有器材清單
  • 確認器材進場時間與運送車輛

當天執行

  • 13:00 進場，場佈就定位
  • 確認每個項目器材齊全
  • 即時補位補缺

賽後收尾

  • 器材清點回收
  • 歸還廠商/機構器材
醫療 / 安全組 組長：JAX　醫護：nikki 負責找一位

賽前準備

  • JAX 設計救護 SOP
  • 通知各教練備急救箱（跌倒防範）
  • 備降溫用品（中暑防範）
  • 備電解質 / 鹽錠 / 能量飲（低血糖防範）

當天執行

  • 醫護全程待命
  • 全場巡視，特別注意高溫時段
  • 緊急事件啟動 SOP 流程

賽後收尾

  • 確認無人員遺留場地
  • 急救物資清點回收
行銷 / 社群組 組長：nikki　乖魚 + 另一位攝影師

賽前準備

  • 規劃必拍清單（平面 + 動態）
  • 設計文宣小物與主視覺
  • 準備運發局貼文草稿
  • 確認影片數量與限動計畫

當天執行

  • 動態攝影 / 平面攝影全程到位
  • 即時發布限時動態
  • 拍攝頒獎 / 捐衣成果 / 大合照

賽後收尾

  • 整理照片 / 影片素材
  • 發布活動結果貼文
  • 提供運發局曝光素材
